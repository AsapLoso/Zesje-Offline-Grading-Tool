Zesje Offline Grading Software

Complete Selenium & AI-powered suite to grade TU Delft student exam submissions offline and sync results back seamlessly.

📂 Structured Repository Layout

The code is divided into four execution steps to organize files, separate data from code, and establish a clear linear workflow.

Zesje Offline Grading Software/
├── config.json                 # Centralized configuration file
├── requirements.txt            # Python dependencies
├── 1_scrape/                   # STEP 1: Scraping scripts
│   ├── zesje_scraper.py        # Selenium image capture scraper
│   └── dump_page.py            # DOM HTML analysis script
├── 2_processing/               # STEP 2: Image and database processing
│   ├── merge_images.py         # Stitches 1b & 1b_ext vertically
│   ├── finalize_exports.py     # Copies & renames to final copy folder
│   └── build_database.py       # Merges CSV grades into clean DB
├── 3_grading/                  # STEP 3: Offline grading clients
│   ├── grader.html             # Standalone touch-optimized browser app
│   ├── auto_grade_1a.py        # Gemini 1.5 Pro AI grading engine
│   └── manual_grade_1a.py      # Terminal manual grader
├── 4_upload/                   # STEP 4: Zesje grade uploader
│   └── zesje_uploader.py       # Selenium grade uploader
└── data/                       # shared local data (gitignored)
    ├── zesje_images/           # Scraped raw png files
    ├── final_exports/          # Formatted png files
    ├── zesje_grades.csv        # Browser grading csv log
    └── grade_database.csv      # final clean database

🚀 The 4-Step Pipeline

1
Scrape Student Submissions

Scrapes student answer screenshots using a headless/headed Firefox Selenium instance. Supports interactive config input.

python 1_scrape/zesje_scraper.py
2
Process & Stitch Images

Stitches two-page submissions (1b and 1b_ext) vertically, structures final copy files, and compiles database updates.

python 2_processing/merge_images.py
python 2_processing/finalize_exports.py
3
Evaluate & Grade Submissions

Open 3_grading/grader.html in a browser and load the scraped images folder to grade manually, or leverage Gemini 1.5 Pro AI to auto-grade math formulas.

python 3_grading/auto_grade_1a.py
4
Upload Grades back to Zesje

Build the final database to sync manual and AI grades, then execute the upload synchronization script to automatically enter grades into Zesje with resumable progress tracking.

python 2_processing/build_database.py
python 4_upload/zesje_uploader.py
🔒 Local Browser Profile Pre-Requisite

Make sure you have logged into the official Zesje platform in your default Firefox browser before running step 1 or step 4. The Selenium driver relies on loading your active Firefox profile (configured in config.json) to authenticate automatically and bypass logging in during automation.
